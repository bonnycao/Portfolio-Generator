# KeelWorks Portfolio Generator

This repository contains UX design assets, documentation, and development resources for the KeelWorks Portfolio Generator project.

## Design Assets

The `design-assets` folder contains assets extracted from the approved Figma designs for development reference.

- `images/` — image assets used in the Figma designs
- `icons/` — icon and SVG assets
- `index.html` — visual gallery for reviewing the extracted assets

## Figma Design

Figma is the primary UX/UI design reference for this project.

## Development

Application source code and additional development documentation may be added to this repository as the project progresses.
